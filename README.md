# X 片思いフィルター (X Following Filter)

X (旧Twitter) のフォローリスト (`/following` ページ) から、「フォローされています」と表示されている相互フォローユーザーを自動的に除外するブラウザ拡張機能です。
自分がフォローしているのに、相手からはフォローされていない（＝片思いの）ユーザーだけを素早く確認・整理することができます。

## ✨ 機能

- **API 段階での事前除外による省メモリ動作**: `/following` の GraphQL レスポンス（`XMLHttpRequest` / `fetch`）の段階で相互フォローや不要なモジュールを除外するため、フォロー数が多い場合でも DOM 肥大化や `Out of Memory` クラッシュを防ぎます。
- **自動ページ送りと進捗ステータス表示**: 相互フォローが連続する区間も自動で次ページを読み進め、画面右上に除外件数・片思い件数・一時停止ボタンを表示します。
- **フォロー解除時の即時非表示**: 一覧上でフォロー解除したアカウントはその場でリストから消え、残り人数が減ると自動で次ページを補充します。
- **API レート制限（429）時の自動再開**: 大量走査時に X 側の API 取得上限に達した場合はリセット予定時刻を表示して待機し、解除後に自動再開します。
- **SPA 対応**: ページ遷移を伴わない X 特有の画面切り替えを検知し、`/following` ページでのみ動作します。

## 🚀 インストール方法

Chrome ウェブストアには公開していないため、開発者モードから手動で読み込んで使用します。

1. このプロジェクトのフォルダをPC上の任意の場所に配置します。
2. Google Chrome または Microsoft Edge を開き、URLバーに `chrome://extensions/`（Edge の場合は `edge://extensions/`）と入力して拡張機能の管理画面を開きます。
3. **「デベロッパー モード（開発者モード）」** のスイッチをオンにします。
4. **「パッケージ化されていない拡張機能を読み込む（展開して読み込み）」** ボタンをクリックします。
5. 本プロジェクトのフォルダを選択して読み込みます。
6. 拡張機能の一覧に追加されればインストール完了です！

## 💡 使い方

1. 拡張機能をインストールした状態で、X (`x.com`) にアクセスします。
2. 「フォロー中」リスト（例: `https://x.com/ユーザー名/following`）を開きます。
3. 自動的に相互フォローのユーザーが除外され、片思いのユーザーのみが一覧に表示されます（右上のボタンから自動読み込みの一時停止・再開も可能です）。

> **Note**: 動作を完全に停止したい場合は、拡張機能管理画面からこの拡張機能のスイッチをオフにし、X のページを再読み込みしてください。

## 🛠 技術仕様

- **Manifest V3** 対応
- **対象URL**: `https://x.com/*`, `*://*.twitter.com/*`
- **アーキテクチャ**:
  - `inject.js` (`MAIN` world / `document_start`): `/Following` GraphQL API のレスポンスから相互フォロー（`followed_by: true`）や凍結・退会済み要素（`UserUnavailable`）を事前破棄し、X の仮想スクロール制限を回避するアンカー管理（`TimelineRemoveEntries` / `TimelineClearCache`）および直列スロットリングを行います。
  - `content.js` (`ISOLATED` world / `document_start`): 進捗バッジ表示、フォロー解除済み行の即時非表示、画面未充足時のスクロール補助を行います。
  - `rules.json` (`declarativeNetRequest`): 画像リソース読み込みを抑止し、さらなる省メモリ化を行います。
