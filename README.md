# X 片思いフィルター (X Following Filter)

X (旧Twitter) のフォローリスト (`/following` ページ) から、「フォローされています」と表示されているユーザーを自動的に非表示にするブラウザ拡張機能です。
自分がフォローしているのに、相手からはフォローされていない（＝片思いの）ユーザーだけを素早く確認・整理することができます。

## ✨ 機能

- `/following` ページを開いた際、「フォローされています」のラベルを持つユーザー要素をDOMから自動削除します。
- メモリの消費を抑え、画面スクロール時の重さを軽減するための高速化処理が施されています。
- X特有のSPA（ページ遷移を伴わない画面書き換え）にも対応し、URLが変わったタイミングで自動的に動作をオン・オフします。

## 🚀 インストール方法

Chrome ウェブストアには公開していないため、開発者モードから手動で読み込んで使用します。

1. このプロジェクトのフォルダをPC上の任意の場所に配置します。
2. Google Chrome を開き、URLバーに `chrome://extensions/` と入力して拡張機能の管理画面を開きます。
3. 画面右上の **「デベロッパー モード」** のスイッチをオンにします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 本プロジェクトのフォルダを選択して読み込みます。
6. 拡張機能の一覧に追加されればインストール完了です！

## 💡 使い方

1. 拡張機能をインストールした状態で、X (x.com) にアクセスします。
2. ご自身の（または任意のユーザーの）「フォロー中」リスト（例: `https://x.com/ユーザー名/following`）を開きます。
3. リストをスクロールしていくと、「フォローされています」という表示のあるユーザーが自動的にリストから削除され、自分だけがフォローしているユーザーのみが表示されるようになります。

> **Note**: 動作を停止したい場合は、Chromeの拡張機能管理画面 (`chrome://extensions/`) からこの拡張機能のスイッチをオフにし、Xのページを再読み込みしてください。

## 🛠 技術仕様

- **Manifest V3** 対応
- **対象URL**: `https://x.com/*`
- **動作タイミング**: `document_idle` 時にスクリプトが読み込まれ、`MutationObserver` で要素の追加を監視します。
- **パフォーマンス最適化**: 軽量な `.textContent` による文字列探索と、処理済み要素への `data-scanned` 属性の付与を組み合わせています。さらに、マッチした要素は非表示（`display: none`）にするのではなく `remove()` で完全に破棄することで、無限スクロール時のDOMツリー肥大化・メモリ増大を防いでいます。
